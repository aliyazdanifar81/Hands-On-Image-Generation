# Hands-On Image Generation with TensorFlow

A personal learning and implementation repository based on the book *Hands-On Image Generation with TensorFlow*.

This repository serves as a collection of code, experiments, notes, and project implementations completed while studying the material presented in the book. The objective is to build practical experience with TensorFlow and modern image generation techniques through hands-on implementation and experimentation.

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
cd hands-on-image-generation-with-tensorflow
```

### Create a Virtual Environment

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
